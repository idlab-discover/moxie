# Historical decomposition inputs

These files preserve the standalone scaffold, diagnostic child and source-pin
workflow. They are not runnable integration commands or current support claims.
`source.json` records the standalone HEAD and hashes of its tracked and unignored
working files, including the pre-existing KernelPCA, LDA and sparse-coding changes.
Current builds use Moxie's DEPENDENCIES.json; the optional Numax build uses the
family's minimal live-owner manifest.
