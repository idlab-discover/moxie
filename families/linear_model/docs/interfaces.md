# Estimator interfaces

The current contract is [Moxie's shared estimator interface](../../../docs/interfaces.md).
It includes typed configuration, clone semantics and borrowed fluent mutation
returns. The reference remains scikit-learn revision
`4358542a1bd39af2e7e1cbace8b9fed067473c5b`.

See [the family API](api-surface.md) for implemented estimators, their concrete
shape adaptations and unsupported modes. Historical scaffold contracts remain
in the source revision recorded by [PROVENANCE.json](../PROVENANCE.json).
