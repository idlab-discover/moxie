# Decomposition development

This family is part of Moxie. Before changing it, read the
[Moxie contributor rules](../../../AGENTS.md),
[family development policy](../../../docs/family-development.md), and
[current interface contract](../../../docs/interfaces.md).

Family-specific source, engines, tests and examples belong here. Shared contracts,
numerical storage, RNG and assembly retain their Moxie owners. Build against
current owner sources. Preserve the compatible Pixi locks, sklearn reference
revision and source provenance; historical snapshots are not build inputs.

The [scope](scope.md) records supported dense behavior and unfinished modes.
Run the focused commands in the [family README](../README.md). Commit validated
changes with explicit paths and preserve unrelated changes in Moxie's index.
