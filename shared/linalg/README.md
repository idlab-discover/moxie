# Shared covariance solves

Pure Mojo covariance adapters using NuMojo storage and existing native numerical
kernels. Read [the API](docs/linalg.md) and [scope](docs/scope.md).

```sh
pixi install --locked
pixi run build
pixi run test
pixi run parity
```

Consume `moxie._linalg` through current shared assembly; follow
[live-source policy](../../docs/family-development.md).
