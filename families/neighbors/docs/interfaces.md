# Shared estimator interfaces

Use [Moxie's current estimator contract](../../../docs/interfaces.md).
Neighbors implements fluent fit and typed set_params, native errors and
Float32/Float64 arrays, with the family-specific adaptations described in
[estimators.md](estimators.md). Historical declarations in `_api.mojo` and
`_trees_api.mojo` are not assembled implementations.
