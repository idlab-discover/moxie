# Common family requirements

This file has 1 purpose and a very specific format.
Each family agent can edit this file in moxie and only this file.
They can put in requests for components that do not belong in their family library.
Concerns / building blocks that are broader than a family implementation.

To avoid overwriting this file the following structure should be used
A family-agent can append to this file, not overwrite in this format:

family-agent (replace family with family name) | request for a building block | expectation of commonality or reason for devolution to moxie itself
