# Smooth losses and optimizers

Private engine project for linear-model consumers. Not implemented yet.
The live dependency assembly and numerical prerequisite probes are retained.
Shared numerical capabilities now exist; engine integration remains unfinished.
See [scope](docs/scope.md).

`pixi run build` and `pixi run test` check preparation and the historical
NuMojo solve exclusion. `pixi run parity` reports the absent native engine.
There is no usable engine example yet.
